# Ekstraklasa-24-25-Referee-Racial-Bias-Analysis
Independent analysis project focused on referee decision-making in Ekstraklasa 24/25, with emphasis on potential racial bias patterns. Includes a set of small Python applications including: web scraping, data cleaning and formatting, enrichment via secondary scraping, and Power-BI visualisation.

workflow:

pip install -r requirements.txt

"python opta_scraper" (--headless | DEFAULT: false)

"python opta_formatter"(--data-in "PATH" | DEFAULT: data/optaformatter/result) (--data-out "PATH" | DEFAULT: data/optascraper/result)

## PL (🇵🇱):
Niezależny projekt analityczny badający boiskowe decyzje sędziów w sezonie 2024/25 Ekstraklasy, ze szczególnym uwzględnieniem potencjalnych wzorców uprzedzeń rasowych.

Projekt obejmuje zestaw aplikacji w Pythonie: zautomatyzowane pobieranie informacji ze stron internetowych, czyszczenie i transformację danych, wzbogacanie danych poprzez wtórne źródła oraz wizualizację i analize w Power BI.
